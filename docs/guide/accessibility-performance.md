# 无障碍与性能

## 无障碍检查清单

- 为文章封面、头像和正文图片填写有意义的 `alt` 文本；纯装饰图片使用空 `alt`。
- 保持标题层级连续，链接文字说明目标，表单或搜索输入提供可见标签。
- 用键盘完成导航、搜索、目录和返回顶部操作，并检查焦点样式没有被自定义 CSS 隐藏。
- 浅色和深色模式都检查文字与背景的对比度；不要只用颜色传达状态。
- 动画或 Canvas 背景应保持非必要。对偏好减少动效的访客，可关闭 `bg_3d`、`canvas_fluttering_ribbon` 等视觉特效，并确保内容仍可读。
- 页面提供“跳转到主要内容”链接；使用键盘 Tab 可先聚焦该链接，再进入导航和正文。

## 性能建议

- 保持 `lazyload.enable: true`，为封面和正文图片提供合适尺寸的压缩资源；优先使用现代格式。
- 首页第一张文章封面和文章页 Hero 会优先加载，其余图片再使用懒加载，避免首屏关键图片被延迟。
- 只启用需要的搜索、评论、统计、分享和聊天服务。第三方脚本会增加请求、执行时间和隐私开销。
- `pjax`、`instantpage` 和 PWA 需要结合部署平台测试；出现脚本兼容问题时，优先关闭单项功能定位原因。
- 发布前执行 `hexo clean && hexo generate`，并用浏览器 Lighthouse 或 Web Vitals 检查移动端首屏、布局稳定性和键盘可用性。

更多字段见[配置字段参考](/config/reference)，第三方资源策略见[安全](/advanced/security)与[CDN 与注入](/advanced/cdn)。
